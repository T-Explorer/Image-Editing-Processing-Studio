# AI 照相馆 · Android 原生版 v2

基于 **Agnes AI 图像模型** 的安卓 App，全新 Material You 风格界面。

- 原生 Kotlin 壳 + WebView 界面，HTTP/图片/文件保存走原生
- 兼容 Android 10+，按 Android 15 编译
- GitHub Actions 云端免费编译，无需 Android Studio
- 支持浅色/深色/跟随系统三种主题，APP 图标已内置

## 主题与设置

- 右上角 **⚙** 打开设置：主题（浅色/深色/跟随系统）、API Key、Base URL、模型、超时、上传上限、长边上限、默认档位，并可测试连接。
- 底部导航栏：证件照 / 换背景 / 精修 / 文生图 / 批量；顶部下拉可切换到写真 / 修复 / 扩图。
- APP 图标：紫色渐变相机 + AI 星芒，已生成各密度 mipmap 与自适应图标。

## 编译与安装

1. 把本目录内容作为仓库上传到 GitHub（Public，Actions 免费）
2. **Actions** → 「Build AI Photo Studio APK」→ **Run workflow**
3. 完成后 **Artifacts** 下载 `AI-Photo-Studio-APK`，解压得 `app-debug.apk`
4. 传手机安装（允许「未知来源」）→ 打开 → 设置里填 Agnes API Key → 测试连接 → 使用

## 隐私

API Key 仅存本机 SharedPreferences；图片仅用于调用 Agnes API；结果保存到「下载/AIPhotoStudio」。证件照/写真请确保已获当事人授权。
